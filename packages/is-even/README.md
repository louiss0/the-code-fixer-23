# @code-fixer-23/is-even

A TypeScript library built with Tsup

**Testing**: vitest

## Installation

```sh
# Using pnpm
pnpm add @code-fixer-23/is-even

# Or using JPD if available
jpd add @code-fixer-23/is-even
```

## Usage

```typescript
import { hello } from '@code-fixer-23/is-even';

console.log(hello());
```

## Development

```sh
# Build the library
npx nx build is-even

# Run type checking
npx nx typecheck is-even
# Run tests
npx nx test is-even

# Lint
npx nx lint is-even
```

# @code-fixer-23/is-prime

A TypeScript library built with Tsup

**Testing**: vitest

## Installation

```sh
# Using pnpm
pnpm add @code-fixer-23/is-prime

# Or using JPD if available
jpd add @code-fixer-23/is-prime
```

## Usage

```typescript
import { hello } from '@code-fixer-23/is-prime';

console.log(hello());
```

## Development

```sh
# Build the library
npx nx build is-prime

# Run type checking
npx nx typecheck is-prime
# Run tests
npx nx test is-prime

# Lint
npx nx lint is-prime
```

# @code-fixer-23/my-lib

A TypeScript library for JSR

## Installation

```sh
# Using JSR
npx jsr add @code-fixer-23/my-lib
```

## Usage

```typescript
import {} from '@code-fixer-23/my-lib';
```

## Development

```sh
# Build the library
npx nx build my-lib

# Run type checking
npx nx typecheck my-lib
# Validate JSR package (dry-run publish)
npx nx validate my-lib
# Publish to JSR
npx nx publish my-lib
```

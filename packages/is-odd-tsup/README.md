# @code-fixer-23/is-odd-tsup

Check if a number is odd using Tsup

**Testing**: vitest

## Installation

```sh
# Using pnpm
pnpm add @code-fixer-23/is-odd-tsup

# Or using JPD if available
jpd add @code-fixer-23/is-odd-tsup
```

## Usage

```typescript
import { hello } from '@code-fixer-23/is-odd-tsup';

console.log(hello());
```

## Development

```sh
# Build the library
npx nx build is-odd-tsup

# Run type checking
npx nx typecheck is-odd-tsup
# Run tests
npx nx test is-odd-tsup

# Lint
npx nx lint is-odd-tsup
```
